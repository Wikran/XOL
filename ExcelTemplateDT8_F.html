Excel Template Processor

Drop your template .xlsx file (template must contain a sheet named Report or will use the first sheet). The template should contain a row with placeholders like {{amount}} (that row), the next row is the directive row (e.g. {sum} or {text: "Total Amount"}), then data rows below. This tool writes the totals row immediately after the data block.

Notes:
  • Directive formats supported:
    • {text: Total Amount} or {text: "Total Amount"}
    • {num: 5000}
    • {formula: =A1+A2} or {formula: A1+A2}
    • {sum}, {average}, {count} — these generate Excel formulas across the data rows
  • Rules: the processor tries text/num/formula first (user override). If none written and directive is sum/average/count, then it writes SUM/AVERAGE/COUNTA across the data range.
  • Totals row is placed right after the last non-empty data row.
